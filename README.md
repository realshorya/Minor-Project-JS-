# 🎮 Simon Says Game

An interactive and responsive **Simon Says memory game** built using **HTML, CSS, and JavaScript**. The game challenges users to remember and repeat an increasingly complex sequence of colors.

# 🚀 Features
- 🎯 Dynamic Gameplay – Sequence increases with each level
- 🧠 Memory Challenge – Improves focus and recall ability
- 📊 Score Tracking – Displays current score and highest score
- 🔄 Start / Restart Functionality – Restart the game after losing
- 📱 Responsive Design – Works smoothly on mobile, tablet, and desktop
- ⚡ Real-Time Feedback – Instant response to user inputs

# 🛠️ Tech Stack
- HTML5 – Structure
- CSS3 – Styling & responsiveness
- JavaScript – Game logic & interactivity

# 🎮 How to Play
1. Click the Start button to begin the game
2. Watch the sequence of colors carefully
3. Repeat the sequence by clicking the buttons
4. Each level adds a new step to the sequence
5. If you click the wrong button → ❌ Game Over
6. Click Start Again to restart

# 💡 Key Functionalities
- Sequence generation using JavaScript logic
- Event handling for user interactions
- Score tracking (current & highest score)
- Responsive UI using CSS media queries
- Button state control (disable after game over)
